# Как добавить слой

Слой подсвечивает здания, связанные одним сюжетом истории, и у каждого здания есть короткая история и источник.
Откройте pull request и в паре фраз опишите слой.

## Ручной слой

Большинство слоёв — списки адресов. Добавьте список в [`pipeline/curated.py`](pipeline/curated.py) (люди и события)
или [`pipeline/curated_places.py`](pipeline/curated_places.py) (места), по образцу соседних:

```python
CINEMAS = [
    # (улица как в OSM addr:street, номер дома, группа, название, история, источник)
    ("Невский проспект", "88", "open", "Кинотеатр «Колизей»",
     "Один из первых кинотеатров Невского, открыт в 1911 году.",
     "https://ru.wikipedia.org/wiki/Колизей_(кинотеатр,_Санкт-Петербург)"),
]
```

и подключите его в [`pipeline/layers.py`](pipeline/layers.py) так же, как подключены `PUSHKIN`, `EGGS` или `BARS`.

Правила:

- **У каждой истории есть источник,** которому можно верить: статья Википедии, городское СМИ, музей. Если источник
  этого не говорит, история тоже не должна.
- **Адрес — нынешний,** как в OSM: улица полностью (`набережная реки Мойки`, а не `наб. Мойки`) и номер дома.
  Пайплайн сопоставляет его со зданием; адреса, которые не нашлись, выводятся в отчёте.
- **Истории короткие:** одно-два предложения, что и когда случилось. Легенды называются легендами.
- **Никаких личных данных частных людей,** кроме того, что уже публично опубликовано открытыми проектами
  (например, «Последний адрес»).

Слою нужно примерно десять зданий или больше; меньший набор лучше добавить группой в существующий слой.

## Слой из открытых данных

Добавьте функцию в `pipeline/layers.py`, которая возвращает здания и группы, и шаг загрузки данных в `pipeline/s00_*`.
Укажите лицензию набора: подходят только открытые данные.

## Проверка

```bash
uv run python -m pipeline.s05_layers
uv run python -m pipeline.s03_tiles
python3 -m http.server 8643 --directory web
```

---

*English: a layer is a list of addresses, each with a short story and a source. Add one to `pipeline/curated.py` or
`pipeline/curated_places.py`, wire it in `pipeline/layers.py`, and open a pull request.*
